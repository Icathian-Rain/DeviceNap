# DeviceNap

DeviceNap 是一款 macOS 菜单栏应用，可在睡眠前关闭整机蓝牙，唤醒后恢复，并在唤醒或登录后尝试重连选中的设备。

[English](README.md) · [贡献指南](CONTRIBUTING.md) · [MIT 许可证](LICENSE)

## 构建和使用

需要 macOS 13 或更新版本和 Xcode 命令行工具（`xcode-select --install`）。从项目根目录运行：

```sh
./build.sh
open build/DeviceNap.app
```

1. 点击菜单栏的月亮图标，可在「唤醒或登录后重连的设备」中选择一台已配对的设备。通过蓝牙地址后缀区分同名设备，已连接的设备排在前面。
2. 如需登录时自动重连上次选择的设备，先把 App 移到「应用程序」，再勾选「登录时启动」。
3. 如果系统要求蓝牙权限，在「系统设置 → 隐私与安全性 → 蓝牙」里允许 DeviceNap。测试前请先退出其他管理睡眠蓝牙状态的工具。

DeviceNap 使用 macOS 自带框架，设备选择保存在本机。

如需防止蓝牙设备误唤醒 Mac，可在菜单栏勾选「睡眠时关闭整机蓝牙」。这会暂时断开所有蓝牙设备。若睡前蓝牙开启，应用会在唤醒后恢复蓝牙。请使用内置键盘、电源键或有线设备唤醒。此模式使用 macOS 未公开的接口，可能受到系统更新影响。

## 单设备睡眠断开暂不可用

实测中，旧版 IOBluetooth 接口对罗技 MX Master 3S 返回断开成功，但多次查询仍显示鼠标已连接。macOS「系统设置」则能单独切断这只鼠标的 BLE HID 链路，同时保持整机蓝牙开启。旧版睡眠测试也记录到蓝牙 HID 活动唤醒了 Mac。该选项已停用，后续会继续探索适合 macOS 的单设备断开方式，并验证设备能否在整个睡眠期间保持断开。

## 排查

如果没有自动重连，唤醒蓝牙设备并选择「立即连接」。在菜单栏选择「查看日志」可查看、刷新或复制最近 30 分钟的记录。日志会显示睡眠与唤醒通知的时间，以及从首次收到屏幕或系统唤醒通知到确认设备连接的耗时。也可以在终端排查：

```sh
build/DeviceNap.app/Contents/MacOS/DeviceNap --check
log show --last 30m --predicate 'subsystem == "local.devicenap"' --info
```

公开提交日志之前，请隐藏蓝牙地址和含个人信息的设备名称。卸载时先取消「登录时启动」，再退出应用并把 App 移到废纸篓。
